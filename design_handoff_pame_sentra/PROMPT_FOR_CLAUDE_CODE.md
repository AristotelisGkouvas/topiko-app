Αντιγράψτε το παρακάτω στο Claude Code, μέσα στο repo του Πάμε Σέντρα, αφού βάλετε τον φάκελο `design_handoff_pame_sentra/` στη ρίζα του repo:

---

Διάβασε το `design_handoff_pame_sentra/README.md` και άνοιξε τα `.dc.html` στο `design_handoff_pame_sentra/designs/` σε browser για να δεις τα σχέδια. Είναι HTML mockups για αναφορά, όχι κώδικας για αντιγραφή.

Υλοποίησέ τα μέσα στο υπάρχον Next.js app, με τα patterns του project, ακολουθώντας τη «Προτεινόμενη σειρά υλοποίησης» του README.

Ξεκίνα από το βήμα 1:
- Διόρθωσε το `metadataBase` (τα `og:image` δείχνουν σε localhost).
- Διόρθωσε το live status ώστε να ελέγχει την ημερομηνία του αγώνα.
- Βάλε `aria-hidden` στα σήματα με αρχικά και στα εικονίδια της κάτω μπάρας.
- Πρόσθεσε τα tokens από το `tokens.css`.
- Αντικατέστησε logo, favicon και εικονίδια του manifest με τα αρχεία του `assets/`.
- Πρόσθεσε πεδίο `shortName` στα σωματεία.
- Φτιάξε τη νέα πλοήγηση (5 tabs στο κινητό, header με dropdown στο desktop).

Πριν γράψεις κώδικα, δείξε μου σύντομο πλάνο με τα αρχεία που θα αλλάξεις. Μετά από κάθε βήμα, σταμάτα για έλεγχο.
