- API:  http://127.0.0.1:8001   (FastAPI· λίστα routes: routes.txt εδώ δίπλα· OpenAPI: /openapi.json)
- Κώδικας: /home/iqsoft/Documents/topiko-app  (frontend/src/app/* σελίδες, frontend/src/components/*, backend/app/*)
- Design mockups (τι ΕΠΡΕΠΕ να γίνει): /home/iqsoft/Documents/topiko-app/design_handoff_pame_sentra/README.md και designs/*.dc.html
- Γνωστά κενά που ο ιδιοκτήτης ΗΔΗ ξέρει: /home/iqsoft/Documents/topiko-app/BACKLOG.md — διάβασέ το ώστε να ΜΗΝ επαναλάβεις τα γνωστά (ζώνες, συντεταγμένες, σήματα, φωτογραφίες, κύπελλο, VAPID, SMS). Αν κάτι από αυτά σε πονάει πολύ ως χρήστη, πες το σε μία γραμμή με τη λέξη «(γνωστό)».

ΔΕΔΟΜΕΝΑ: seed/dev data. 1 ένωση, 1 κατηγορία (Α΄ Κατηγορία, 10 ομάδες), 90 αγώνες. Ποιοι αγώνες είναι live αυτή τη στιγμή: GET /api/v1/epsip-ipeirou/matches/live (το seed ξεκινά με δύο, οι δοκιμές εθελοντών τούς αλλάζουν). Τα σκορ/ημερομηνίες είναι πλασματικά. Μην αναφέρεις ως bug ότι «λείπουν κατηγορίες/ομάδες»· ΣΚΕΨΟΥ όμως πώς θα ήταν με 15 κατηγορίες και 177 ομάδες (η πραγματική ΕΠΣ) και πες αν το UI θα άντεχε.

## Εργαλεία
Headless browser με Playwright (κάνει κλικ, γεμίζει φόρμες, screenshot, τυπώνει κείμενο σελίδας, console errors):
  python browse.py   (με Playwright: python3 -m venv .pw && .pw/bin/pip install playwright && .pw/bin/playwright install chromium) URL out.png [--desktop] [--full] [--dark] [--text] [--fresh] [--slow3g] [--do 'click:CSS ή text=Κείμενο'] [--do 'fill:CSS=κείμενο'] [--do 'press:Enter'] [--do 'wait:800'] [--do 'goto:URL'] [--do 'scroll:600'] [--do 'eval:JS'] [--storage KEY=VAL]
  - SCRATCH = ο φάκελος όπου τρέχεις (docs/ux-review ή scratchpad)
  - Δώσε ΔΙΚΟ ΣΟΥ όνομα αρχείων (π.χ. p3_home.png) και --state SCRATCH/p3-state.json για να μη μπλέκεις με τους άλλους agents.
  - Δες τα PNG με το εργαλείο Read (τα βλέπεις ως εικόνα). Χρησιμοποίησε --full για ολόκληρη τη σελίδα.
  - Επίσης: curl στο API, και ανάγνωση κώδικα για να επιβεβαιώσεις ΓΙΑΤΙ συμβαίνει κάτι.
  - Μην αλλάζεις κώδικα. Μην σταματάς containers. ΜΗΝ τρέχεις scraper.

## Τι παραδίδεις (στα ΕΛΛΗΝΙΚΑ, ως ο χρήστης-persona, αλλά συγκεκριμένα και επαληθευμένα)
1. **Τι προσπάθησα να κάνω** (3-6 σενάρια) και τι έγινε σε καθένα (πέτυχε / δυσκολεύτηκα / απέτυχε), με URL.
2. **Τι δεν μου άρεσε** (γούστο, κείμενα, ορολογία, χρώματα, ιεραρχία).
3. **Τι με δυσκόλεψε** (πλοήγηση, εύρεση, πατήματα, κατανόηση).
4. **Προβλήματα / bugs** — κάθε ένα με: σελίδα/URL, τι έκανα, τι περίμενα, τι είδα, σοβαρότητα (Κρίσιμο/Σοβαρό/Μέτριο/Μικρό), και αν το επιβεβαίωσες στον κώδικα (αρχείο:γραμμή).
5. **Πιθανές λύσεις** για καθένα, ρεαλιστικές για ένα μικρό project.
6. **Προσθήκες που θα ήθελα** (max 5, με σειρά αξίας για ΕΜΕΝΑ τον persona).
Να είσαι αυστηρός αλλά δίκαιος· πες και τα 2-3 πράγματα που σου άρεσαν ΠΡΑΓΜΑΤΙΚΑ. Όχι γενικότητες: κάθε ισχυρισμός με απόδειξη (screenshot που είδες, κείμενο σελίδας, απάντηση API, κώδικας). Μέγεθος αναφοράς: 600-1200 λέξεις.
